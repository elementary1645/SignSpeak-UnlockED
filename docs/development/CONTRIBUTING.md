# Contributing

Use a focused feature branch and descriptive commits. Keep generated databases, datasets, artifacts, dependencies and secrets out of Git. Update dependency lockfiles when manifests change and describe upstream provenance in ORIGINALITY.md.

Run the README checks before pushing. Exercise keyboard focus, narrow screens and empty/error states for interface changes. Update both protocol implementations, tests and documentation together. When adding functionality, keep transport availability distinct from feature readiness and label planned capabilities. Add database migrations with the first persistent entities.
